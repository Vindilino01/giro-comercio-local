CAP: o erro que quase todo trabalho comete

O erro comum

  • Errado: "escolhemos CP"
  • O MVP é nó único — não é sistema distribuído, então CAP não se aplica.

Análise correta

  • Correto: análise condicional, por caminho
  • Baixa de estoque → CP: recusar a venda é aceitável
  • Dashboard → AP: número de 2 min atrás é aceitável
É uma decisão por caminho, não do sistema.
